## 失败与边界

- build failure、no-supported-pattern 和 deferred 均进入 taxonomy，不是安全结论。
- 20-crate 输入没有达到约 100-crate 规模；不得外推生态比例。
- `dynamic_ready=4` 只完成 effort accounting，没有 harness/trace/oracle 动态运行。
- historical `rank-lifecycle` 是早期模板构图/打分，不能替代当前 graph-v3 proof-layer 语义。
- `method_negative_count=0` 是有意约束：本阶段深度不足以产生方法阴性。

结论：V3.2 20-crate 工程格式和 formal rollup 在历史 revision 上闭环，但 `enter_full_v3_3=no`；该结论没有被当前迁移 commit 的最新 gate 更新。
