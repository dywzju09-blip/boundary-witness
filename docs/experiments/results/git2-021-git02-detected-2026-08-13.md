# git2 GIT-02（Revwalk hide_cb UAF）检测修复：guard 判据 + guard 拆除生成

- 日期：2026-08-13
- 前置：git2-021-candidate-verification-2026-08-13.md（GIT-01/GIT-02 候选验证）
- 状态：**GIT-02 工具端到端检出——ASan heap-use-after-free 出证（unseen 候选）**

## 1. 三个修复

### A. guard 判据漏掉"回调参数类型上的 lifetime"

`Revwalk::with_hide_callback(&'cb mut C) -> Result<RevwalkWithHideCb<'repo,'cb,C>>`：
'cb 在参数（&'cb mut C）上，不在 C 的 where bound 上 → bound_lifetimes 空 →
`guard_bound_lifetime_absent` → Unresolved。修复：guard 判据合并参数类型上的
lifetime（新增 `ty_references_type_param`，穿透 Box/Option/&/fn ptr/tuple/trait
bound/类型实参）。结果：guard=unresolved → **none**（正确：RevwalkWithHideCb 无
Drop 注销）。

### B. decide_invalidate 对 guard=Unresolved 不再直接拒绝

guard=Unresolved 是缺证不是"guard 绑定"。修复：Unresolved → Generated（尝试生成，
编译裁决：真绑定 → E0505 编不过 = 负对照；假 guard → 编过 → 候选）。

### C. 生成器 guard 拆除形状

guard 类型层绑定使 drop(referent) 被借用检查拒绝（E0505）——分离必须经拆除方法
（into_inner 返回不含 'cb 的 Revwalk）。生成器扩展：`callback_by_ref` +
`guard_removal_method`；渲染 `let mut bw_guard = revwalk.with_hide_callback(&mut
callback)?;` + `let mut bw_guard = bw_guard.into_inner()?;`（先拆 guard 再 drop
referent）。adapter 只描述合法调用；分离时序由判定推出。
