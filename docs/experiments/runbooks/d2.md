# D2 小规模对照

## 目的

D2 对比 `random_action`、`coverage_only` 和 `coverage_state` 三组，验证统一 records、artifact/replay 和 contract-state feedback 计数链路。当前 5-campaign 配置只用于工程验收，不支持显著性声明。

## 输入

- `experiments/configs/d2-baselines.toml`；
- D1 `update_hook` safe fragments 与 objective policy；
- 新的 records root；
- 相同 seed list、最大序列长度、目标 build、sanitizer、机器和预注册预算。

## 禁止输入

禁止样本答案、完整危险 seed、跨组共享的可变 libFuzzer corpus，以及从前一组复制的 discovered artifact。不得把 `random_action.execution_budget=1000` 解释成真实 10 CPU-minutes。

## 前置检查

1. `tools/experiment/run-d2-small.sh` 与 `verify-d2-comparison.sh` 存在。
2. 为每个 run、group、campaign 建立独立 corpus；records root 必须为空。
3. 当前配置中的 corpus/objective digest 是测试哨兵值，新 formal 必须用真实 hash 形成新 config revision。
4. 当前实现强制 config 形状、group CPU/max sequence/seed membership，以及 coverage 组 sanitizer；它**不证明** runner 实际使用的 initial corpus、objective policy、target build 与 shared digest/ID 一致。
5. 当前 rusqlite benchmark lock 阻塞脚本内部 `cargo --locked`，因此最新 D2 formal 为 **Blocked**，未执行。

## 精确命令入口

只验证配置与 summary 形状，不生成 campaign：

```bash
tools/experiment/verify-d2-comparison.sh \
  experiments/configs/d2-baselines.toml
```

在修复真实 digest 与 benchmark lock 后，使用全新的 records root生成三组 records：

```bash
BW_D2_GENERATE_RECORDS=1 \
BW_D2_RUSTUP_TOOLCHAIN=nightly-2026-07-08 \
tools/experiment/run-d2-small.sh \
  experiments/configs/d2-baselines.toml \
  "${BW_RECORDS_ROOT:?}"
```

重新汇总并校验已有 records：

```bash
tools/experiment/verify-d2-comparison.sh \
  experiments/configs/d2-baselines.toml \
  "${BW_RECORDS_ROOT:?}"

tools/experiment/run-d2-small.sh \
  experiments/configs/d2-baselines.toml \
  "${BW_RECORDS_ROOT:?}"
```

## 输出

三组各有 `campaign-records.jsonl`；coverage campaign 还保留独立 corpus、counters、artifact、decoded/minimized/replay 与日志；run 根保存 `d2-comparison-summary.json`。summary 报告 status、success、time-to-first、valid ratio、minimized length、replay、progress state coverage 与 secondary count。

## 失败分类

- `configured`：只验证配置，不是完成结果；
- `no_primary`/`timeout`/`tool_error`：逐 campaign 统计；
- `budget_not_comparable`：CPU 或 execution budget 口径不一致；
- `corpus_contamination`：复用非空 base/campaign corpus，整次 run 作废；
- `alignment_failure`：digest、seed、target 或 sanitizer 未证明一致；
- `integrity_failure`：records 或 checksum 不完整。

## 结果归档

保存所有组的 records 与 shared-budget manifest，明确 random baseline 的实际停止条件。只有 `status=completed` 且对齐字段可验证时才可比较；小样本结果仍标为 pipeline acceptance。

## 清理

每组完成后可删除大体积变异 corpus，但须在 checksum manifest 中明确排除并保留 base corpus hash、代表 artifact 和 campaign records。污染或中止 run 保留 abort record，不并入有效结果。
